📋 1.5 通用输入文件格式规范

以下是各模块共用的标准文件格式定义。各模块输入表中的「格式」列引用此处编号。

编号文件名模式格式列要求说明
F1expression.csv / *.dat.csvCSV, UTF-8第一列 SYMBOL（基因名），其余列为样本，值为数值型表达量行=基因，列=样本。支持 raw counts / log2 / TPM
F2group.csvCSV, UTF-8sample, groupsample 值必须与表达矩阵列名精确匹配
F3gene.csv / genes.csvCSV, UTF-8SYMBOL（或 gene），每行一个基因名通常来自 DEGs / Venn / MachineLearn 输出
F4survival.csvCSV, UTF-8sample, OS.time(天数), OS(0/1)也支持 DFS.time/DFS、PFS.time/PFS 等终点
F5riskscore.csv / rs_dat.csvCSV, UTF-8sample, riskscore, riskgroup来自 Prognosis 模块输出

F7gse_list.txt纯文本每行一个 GSE ID（如 GSE126124）批量下载模式使用

脚本用途

    # 第一步：只浏览候选列 /media/share/secure/gse_download_and_cleaning/run_extract_groups.sh \ -f GSE126124_pdata.csv # 第二步：指定列并预览映射 /media/share/secure/gse_download_and_cleaning/run_extract_groups.sh \ -f GSE126124_pdata.csv \ -c "disease_state" \ --map "tumor=Tumor" \ --map "normal=Normal" # 第三步：确认后输出到文件 /media/share/secure/gse_download_and_cleaning/run_extract_groups.sh \ -f GSE126124_pdata.csv \ -c "disease_state" \ --map "tumor=Tumor" \ --map "normal=Normal" \ -o groups.csv

🔧 26. 故障排除

常见问题

现象可能原因解决方案
Permission denied 权限配置不正确或脚本路径错误 确认免密调用已配置（见第 0 节前置条件），检查脚本路径是否正确
R 包缺失报错 依赖包未安装 运行 ./run_*.sh --install-deps（部分模块支持）
输入文件格式错误 CSV 编码问题 / 列名不匹配 确认 UTF-8 编码，检查列名是否为 SYMBOL、sample、group
输出目录删除失败 非创建者尝试删除 按该模块 --help 使用清理入口；模块会独立复核调用者、目标路径和删除授权
GEO 下载缓慢 NCBI 直连网络差 默认使用 geoChina 镜像，或指定 --no-geochina 切回 NCBI
MR OpenGWAS 报错 API token 过期 运行 update_opengwas_token.sh 更新 token
log2 变换后数据异常 数据已是 log 尺度但被重复变换 GSE 下载模块自动检测 log2 状态，通常无需手动干预

日志、缓存与报告

📋 按实际能力查看：
  • log/：新建或升级模块以 run_record.json 统一记录运行事实，并按需保存配置快照；既有 logs/ 路径仅是历史实况
  • cache/：仅在后续命令真实复用时保存有版本对象，不另建 manifest；缓存无效时不得静默重算
  • result/：只保存业务或科学分析结果，不保存审核、判断、证明或参数回显文件
  • report/：新建或升级模块的正式报告固定进入此目录；下表若记录报告位于 result/，仅表示存量兼容差距
遇到问题时，先读取 .run_id 获取最近成功调用标识，再查看固定阶段日志并核对其中的 run_id；失败运行按其输出的日志路径排查。
